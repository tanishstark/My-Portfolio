## 🚀 Key Features

- 🌌 **Interactive Constellation Particle Canvas:** Dynamic nodes reacting smoothly to mouse movements and viewport shifts.
- 💻 **Interactive CLI Terminal Simulator:** Run real-time commands (`skills`, `projects`, `education`, `contact`, `whoami`, `sudo hire`, `clear`).
- 🤖 **Interactive GenAI Career Assistant:** Simulates a live AI model answering questions about Tanish's experience and background.
- 🗂️ **Filterable Skills Arsenal:** Instant discipline filtering (Languages, Core Java & CS, Web & Backend, Databases, AI/GenAI, Tools) with animated skill meters.
- 🛠️ **Project Deep-Dive Modals:** Comprehensive architecture breakdowns, key feature checklists, and code snippets for:
  - **Travellers Villa:** Full-stack solo hotel booking platform with Maps API, Admin controls, and role-based auth (Node.js, Express, MongoDB).
  - **Book Harbor:** Multi-genre e-commerce bookstore with dynamic search, filters, and relational schema (PHP, MySQL, JavaScript).
  - **Synthesis GenAI Suite:** Contextual AI orchestration and prompt engineering pipelines.
- 📜 **Dual Experience & Education Timeline:** Highlights internship at *Academy of Skill Development / UGCPL*, MCA in GenAI at *SRM IST*, and BCA at *Sarala Birla University*.
- 🌓 **Theme Switcher:** Seamless switching between Cyber Dark and Crisp Light modes with persistent state in `localStorage`.
- ⚡ **Zero External Heavy Dependencies:** Pure Vanilla HTML5, CSS3, and JavaScript for blazing fast Core Web Vitals (LCP/INP).
- ☁️ **Vercel Ready:** Pre-configured with `vercel.json` for one-click deployment, clean URLs, and HTTP security headers.

## 💻 Local Development

Run the portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/tanishstark/my-portfolio.git

# 2. Navigate to project root
cd my-portfolio

# 3. Serve locally with any static server (or VS Code Live Server)
npx serve .
```

Open your browser at `http://localhost:3000`.

## ☁️ Deployment to Vercel

### Option 1: Automatic GitHub Integration (Recommended)
1. Push this repository to your GitHub account: `https://github.com/tanishstark/my-portfolio`.
2. Navigate to your [Vercel Dashboard](https://vercel.com/tanishstark1234-8024s-projects).
3. Click **"Add New Project"** -> **"Import Git Repository"**.
4. Select `my-portfolio` and click **"Deploy"**. Vercel will automatically detect the static project and deploy instantly!

### Option 2: Deploy via Vercel CLI
```bash
# Install and log in to Vercel CLI
npm install -g vercel
vercel login

# Deploy directly to production
vercel --prod
```
